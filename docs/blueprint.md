# **App Name**: PNG2SVG Studio

## Core Features:

- Drag & Drop Image Upload: Users can effortlessly upload up to 5 PNG images, each with a maximum size of 10MB, using an intuitive drag-and-drop interface or file selection, with immediate client-side validation for file type and size.
- Image Previews & Adjustments: Provides clear previews of uploaded PNGs and generated SVGs. Users can finely adjust the width and height of each image prior to conversion.
- Client-Side PNG to SVG Conversion: Performs robust conversion of PNG raster images into scalable vector graphics (SVG) entirely within the browser using 'imagetracerjs', ensuring user data privacy and performance.
- Conversion Feedback & Error Handling: Displays clear progress indicators and loading spinners during the conversion process. Comprehensive error messages are provided for invalid file uploads, conversion failures, or other issues.
- SVG Output & Download: Presents an interactive preview of the generated SVG files. Users can download individual SVGs or initiate a batch download of all converted files.
- Modern Responsive Design: A clean, minimalistic user interface that adapts seamlessly across various devices and screen sizes, enhanced with a user-friendly dark mode for comfortable viewing.

## Style Guidelines:

- Primary color: A bold and reliable blue, #2563eb, symbolizing efficiency and technology. This hue contrasts effectively against the dark background.
- Background color: A very deep, desaturated blue-black, #0f172a, serving as the core of the dark mode theme. This color provides a sleek and professional canvas.
- Accent color: A vibrant and distinct green, #22c55e, for key interactive elements like buttons and highlights, providing clear calls to action.
- Body and headline font: 'Inter' (sans-serif), chosen for its modern, clean lines and excellent legibility across all screen sizes. Note: currently only Google Fonts are supported.
- Simple geometric vector icons that clearly represent functionality. The logo will visually depict a PNG transforming into SVG vector lines, emphasizing the app's core purpose.
- A modern and minimalistic layout with a clear hierarchy of content. The interface will feature distinct sections for upload, previews, controls, and output, maintaining ample white space for visual clarity on all screen sizes.
- Subtle, fluid animations powered by 'framer-motion' will provide polished visual feedback for user interactions, such as file uploads, conversion progress, and state changes.
